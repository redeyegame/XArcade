Methodology and release requirements

A living standard for evidence quality, privacy, and reproducibility.

Verification vocabulary

01
Confirmed

Directly supported by an identified primary record or reliable independent reporting, scoped to what that record proves.

02
Reported

Attributed to a source, but not independently established by this index.

03
Disputed

Conflicting evidence or express contest by a party; unresolved here.

04
Needs review

Source or classification not yet verified. Do not present as fact.

Release checklist

Every published assertion should link to a source. Each PDF should retain an original file and SHA-256 hash in the private preservation archive, with a separately reviewed, redacted public copy if appropriate.

Use an explicit corrections history, verify court dates directly, request responses from adversely portrayed subjects, and distinguish allegations, legal filings, judicial findings, and editorial opinion.

Do not bulk scrape a court website without checking its terms and permissions. The browser import feature uses only files you provide.

Accepted JSON data structure

The downloadable template is an empty dataset. No historical, case-specific, or statutory facts are prefilled.
